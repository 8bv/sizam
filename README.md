# Шлюз взаимодействия с Wiki2035 API
Позволяет производить массовые действия с платформой.

## Использование
Для работы сервиса необходимо предоставить следующие переменные окружения:
- `DB_URI` - адрес для подключения к БД в которой будут сохраняться результаты
- `API_KEY` - ключ апи от платформы Wiki2035
- `COMPANY_NAME` - идентификатор компании, в Wiki2035 называется `platform_id`
- `BASE_URL` - базовый URL

Запуск производится командой `uvicorn sizam.api.main:create_app --factory`

## Установка
Необходимо склонировать себе репозиторий и выполнить команду `pip install .`

Следующим шагом предоставив переменную окружения `DB_URI`
накатить миграции выполнив команду `alembic upgrade head`
